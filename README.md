My main template for competitive programming.

# Usage
- `input.txt` for input
- `output.txt` for output (with code duration time)
- use `ll` for long long
- use `vi` for `vector<long long>`
- use `cin >> v` to input the vector
- use `cout << v` to print the vector
- use `debug(x)` to debug x only for you

# Contributing
1. Fork a repo
2. Create your branch
3. Commit your changes
4. **IMPORTANT** go to [Snippet Generator](https://snippet-generator.app), generate snippet and fill the `template.json`
4. Push to the branch
5. Open a pull request
